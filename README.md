\# Guess the Distribution Game

A browser game for training intuition about probability distributions and stochastic processes. You're shown a histogram or a simulated path and pick which model generated it.



\## Play

Open `index.html` in any browser. No install or build step.



\## What's in it

\- Histograms: Normal, Lognormal, Student-t, Laplace, Uniform

\- Paths: Brownian motion, geometric BM, Ornstein–Uhlenbeck, jump diffusion

\- The sample size shrinks as your streak grows, so rounds get harder

\- Optional stats hint (skew, excess kurtosis, tail mass) at half points



\## Controls

Number keys pick an option, H shows stats, Enter moves to the next round.
